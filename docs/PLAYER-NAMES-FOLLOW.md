# 人物名字与动态跟随（v15，本地候选版）

- 名字来自现有服务端实体快照的 `Player.Name`（Controller `m_iszPlayerName`），不是把声源当人物，不额外扫描客户端内存。
- 绘图协议 v3 在人物上增加可选 `name`：最多32个Unicode字符、删除控制/双向格式符、规范空格。不下发SteamID、原始实体编号、世界坐标、密钥或Token。
- v1/v2输出保持原样。新版原生端请求v3；仅收到受信HTTPS端“400 + 精确 unsupported drawing version”时重新签名、以新nonce协商v2一次，之后记住v2，不增加持续轮询预算。403、其他400、5xx、超时、坏帧依旧失败关闭。
- 旧服务端下可以用随机会话代号选择人物并跟随，但不会伪造真实名字；显示真实名字需要配套v3后端上线。没有名字时显示代号，同名也用会话代号区分。
- 中文名字是canvas纯文本、下拉项用textContent；名字不进入HTML、URL、本地道具JSON或诊断日志。名字开关与标签避让保留，跟随目标标签优先，密集时可放大。
- 在地图点选人物或在图层页的列表选择，点击“跟随所选人物”。视口中心跟随当前有效像素插值，原图/人物/声音/参考层同步平移。只跟随平移，不旋转地图，不新增朝向功能。
- 拖动、居中/数字0、Esc、停止按钮、道具浏览/编辑退出跟随。目标消失/死亡/离开有效视图、切图、会话代际变化、过期或授权失效时停止。目标回来获得新随机ID后必须重新选择；不会凭同名自动追到另一个人。

地图仍全部在本地，v14的中文标注、道具库、编辑与备份保持。不改PVS、解码判据、实体新鲜度和本地解析回退策略。

本次只交付本地客户端和未签名后端候选，不代表线上已更新。签名、维护切换与重启需要新的明确授权。真实对局及浏览器画面验收状态以交付报告为准。
