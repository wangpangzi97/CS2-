# gamesense v16 · 只读观看

## 同局域网手机
在主机正常授权并打开雷达后，进入图层 → 只读观看分享。选择可信局域网和实际网卡 IP，确认 HTTP 明文风险，点击开启分享，把完整临时链接发给手机浏览器。默认端口 18083，可修改；不会自动修改防火墙。手机和主机需在可互通的私有网络，访客 Wi-Fi/AP 隔离可能阻断。确有需要时只允许 Windows 专用网络对应观看端口，不关闭防火墙，不做公网端口映射。

## 自行内网穿透
先从穿透软件取得 HTTPS 根地址，再在分享面板选择穿透模式，填写准确根地址。软件仅转发到本机 127.0.0.1:观看端口，保留路径，Host 可为该公开域名或该 loopback 监听地址。应用忽略 Forwarded/X-Forwarded-*，以显式配置的公开 HTTPS origin 检查浏览器请求。外部 HTTPS 终止、有效证书和穿透入口访问控制由使用者配置，本包不安装或运行任何穿透软件；未做真实公网穿透验收。不支持 URL 子路径挂载。

## 权限与生命周期
默认不建立观看监听。独立随机 256-bit 邀请，不使用卡密、主机 token 或设备私钥。邀请只放 URL 片段，浏览器先移除片段，再同源 POST 换 HttpOnly/SameSite=Strict 只读 Cookie；穿透模式 Cookie 为 Secure。片段不进入 HTTP 请求、Referer 或访问日志，不写 localStorage。链接属于观看能力，持有人可加入；不要公开传播。观看凭证仅存在内存，重启不会恢复。局域网 HTTP 本身不保密，邀请和数据可能被同网攻击者截获，只有可信网络才可使用。

分享最长 60 分钟，最多 5 个活跃 Cookie 会话，每个观看端离线 2 分钟释放名额。统计是会话数，不代表独立人数；同浏览器标签共用会话，持有人也可能转发。停止后再开启会产生全新邀请和 Cookie 名。到期、停止、主机退出或授权失败均销毁会话并关闭端口。主机视图过期不返回数据；浏览器以请求开始时刻计算至多 1 秒有效期，超时/失败/页面隐藏清除人物、声音、底图及跟随，不展示旧点位。

只读服务只提供页面、脚本、当前合法 PNG 和当前已授权绘图 DTO。没有数据采集、卡密登录、设备凭据、原始包、世界坐标、实体索引、远端代理、后台、换图或点位写入端点。局域网只绑定用户选中的私有 IPv4 接口，拒绝公网来源；穿透只绑定 127.0.0.1，拒绝其他来源。原本的 loopback 原生桥接鉴权不改变。全局限速 200 req/s、登录 10次/分钟、请求体/头与响应时限均有界；它不是公网防 DDoS 网关。

观看端支持本地原图、T/CT 配色、人物名字纯文本及标签避让、独立跟随、滚轮/双指缩放、单指拖动和居中。不允许观看端改变主机选图，不提供道具编辑或道具截图库。目标消失、换图或换会话停止跟随，不按同名重锁。不含二维码功能，使用复制完整链接。
