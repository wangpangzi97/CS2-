================================================================
一、这次改了什么
================================================================

1) 彻底删除 Npcap 后端（internal/pcapdev 重写为纯 raw socket）
   只保留一条路：
     socket(AF_INET, SOCK_RAW, IPPROTO_IP)
       → bind(fd, 本机网卡 IPv4)
       → WSAIoctl(fd, SIO_RCVALL = 0x98000001, ON)   双向抓包
       → WSARecvFrom(fd, ...)                        逐包取回
       → GetExtendedUdpTable(...)                    端口过滤（internal/capturefilter）

   删掉的：wpcap.dll 全部代码、ListDevices(pcap_findalldevs)、SetBuffer、
   SetMinToCopy、SetFilter/SetLocalUDPFilter、BackendNpcap、ParseBackend、
   NpcapAvailable、NpcapPath、-backend / -dev 参数。
   连"只收接收方向"的 ip4:udp 降级路也删了 —— 那条路拿到包也没用（拿不到握手），
   留着只会让人误以为在正常工作。

2) 新增单文件窗口版 CS2雷达.exe（-H=windowsgui，双击即用，不用 cmd）
   - ShellExecuteExW("runas") 自提权
   - 原生 Win32 窗口：状态行 + 日志框 + 「打开雷达页」/「停止并退出」
   - stderr 重定向到管道 → 日志框（不改抓包代码就能显示日志）
   - 启动后自动用默认浏览器打开雷达页
   同一份代码编出两个 exe：
     capture.exe    subsystem=3（控制台），排障用
     CS2雷达.exe    subsystem=2（GUI，无控制台窗口）

【期间修掉一个真 bug】第一版窗口关不掉：WM_CLOSE 分支只调了 stopAndQuit()

（sess.Wait）交给消息循环退出后的 run()。重测通过。

十、复验：补上提权分支测试后重建（2026-10-16 23:2x）
================================================================

【为什么重建】提权逻辑此前一条测试都没有。本轮在 gui.go 加了一个间接层：

    var isAdminFn = winapiIsAdmin     // 生产路径恒等于 winapiIsAdmin
    ensureElevated() 改调 isAdminFn()

这样三条分支里两条能离线覆盖，不用真的把自己降成非管理员。

$ go test -v -count=1 -run 'TestEnsureElevated|TestBuildArgLine|TestWin32' ./cmd/collector/
=== RUN   TestWin32ProcsResolve
--- PASS: TestWin32ProcsResolve (0.00s)
=== RUN   TestEnsureElevatedAlreadyAdmin
--- PASS: TestEnsureElevatedAlreadyAdmin (0.00s)
=== RUN   TestEnsureElevatedStopsLoopWhenStillNotAdmin
--- PASS: TestEnsureElevatedStopsLoopWhenStillNotAdmin (0.00s)
=== RUN   TestBuildArgLine
--- PASS: TestBuildArgLine (0.00s)
PASS

其中 TestEnsureElevatedStopsLoopWhenStillNotAdmin 覆盖的是最危险的一条：
带 -elevated 重入却仍非管理员（用户点了 UAC「否」）→ 必须报错退出，
绝不能再 ShellExecuteExW 一次，否则就是无限弹 UAC 的死循环。
该用例刻意只走 flagElevated=true 分支；flagElevated=false 那条会真的弹 UAC，不碰。

TestBuildArgLine 覆盖重入命令行的重建：保留原参数、追加 -elevated、
带空格的参数（如 "C:\Program Files\..."）必须加引号。
